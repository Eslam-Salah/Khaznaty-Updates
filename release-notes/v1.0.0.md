# خزنتي — الإصدار الرسمي الأول 1.0.0

مرحبًا بك في أول إصدار رسمي من خزنتي.

- صفحة مستقلة **التحديثات** داخل الإعدادات، تعرض الإصدار المثبّت.
- زر **التحقق من التحديثات** يُظهر إن كنت على أحدث إصدار، أو يوجد تحديث، أو تعذّر الاتصال.
- تنزيل ملفات تحديث APK داخل خزنتي مع شريط تقدّم، وفحص اسم الحزمة وشهادة التوقيع قبل التثبيت.
- بعد أي تحديث لاحق، تظهر رسالة **ما الجديد** مرة واحدة.
- تنظيم واجهة الإعدادات وحول خزنتي، مع تواصل مباشر مع المطور.
- تخزين محلي مشفر والنسخ الاحتياطي والاستعادة دون تغييرات على البيانات.

**الإصدار:** `1.0.0`  
**رقم البناء:** `1`  
**اسم الحزمة:** `com.khaznaty.vault`
