# خزنتي | Khaznaty — Official Android Releases

مستودع **عام للتحديثات الموقّعة فقط**. كود التطبيق محفوظ في مستودع خاص منفصل.

## أول إصدار رسمي
- الإصدار الحالي: **1.0.0** (`v1.0.0`)
- رقم البناء: **1** (`versionCode = 1`)
- اسم الحزمة: `com.khaznaty.vault`
- تنزيل النسخة: [Khaznaty v1.0.0](https://github.com/Eslam-Salah/Khaznaty-Updates/releases/tag/v1.0.0)
- أحدث إصدار: [Releases/latest](https://github.com/Eslam-Salah/Khaznaty-Updates/releases/latest)

## آلية التحديث
خزنتي يفحص إصدار `releases/latest` من داخل الإعدادات ← التحديثات، وكذلك عند فتح التطبيق عند توفر الاتصال. إذا كان إصدار أحدث متاحًا، يعرض وصف التغييرات ويحمّل ملف APK داخليًا، مع التحقق من شهادة التوقيع قبل عرضه للتثبيت. يتطلب Android موافقة المستخدم على شاشة تثبيت النظام.

## سياسة الإصدارات اللاحقة
النسخة الأولى `1.0.0` برقم بناء `1`؛ التحديث القادم يكون `1.0.1` برقم بناء `2`. يجب زيادة `versionCode` في كل إصدار لاحق، مع استخدام **نفس** مفتاح التوقيع الرسمي.

1. أضف `release-notes/vX.Y.Z.md` بمميزات الإصدار الجديد.
2. وقّع APK بالمفتاح الرسمي وتأكد من اسم الحزمة ورقم البناء.
3. ارفع `uploads/Khaznaty-X.Y.Z-Release-SIGNED.apk`.
4. تنشئ GitHub Actions الإصدار العام، وتتحقق من التوقيع وملف التثبيت.

**الأمان:** لا ترفع الكود الخاص أو ملفات `.jks` أو كلمات مرور المفاتيح أو قواعد بيانات أو ملفات المستخدمين لهذا المستودع.

**تنبيه الترقيم:** إصدارات التجربة السابقة برقم بناء أعلى من 1 لا تقبل تثبيت `1.0.0` كتحديث مباشر. خذ نسخة احتياطية قابلة للاستعادة قبل إزالة أي نسخة تجريبية قديمة.
