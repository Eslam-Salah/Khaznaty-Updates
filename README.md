# خزنتي — Khaznaty Official Android Releases

هذا المستودع العام مخصص لتوزيع **ملفات APK الموقّعة وملاحظات الإصدار**. لا يحتوي على كود التطبيق أو بيانات المستخدمين أو مفاتيح التوقيع.

## الإصدار الرسمي الأول
- الإصدار: **1.0.0**
- رقم البناء الداخلي: **1**
- اسم الحزمة: `com.khaznaty.vault`
- أحدث إصدار: https://github.com/Eslam-Salah/Khaznaty-Updates/releases/latest
- فحص التحديثات داخل خزنتي من **الإعدادات ← التحديثات ← التحقق من التحديثات**، مع تنزيل APK داخليًا عند توفر إصدار أحدث.

## التوزيع والنشر
1. تُجهز النسخة الموقّعة بالمفتاح الرسمي خارج GitHub وتُفحص شهادة توقيعها.
2. تُضاف ملاحظات إصدار جديد باسم `release-notes/vX.Y.Z.md`.
3. يُرفع `Khaznaty-X.Y.Z-Release-SIGNED.apk` إلى مجلد `uploads/`.
4. ينشئ GitHub Actions إصدارًا عامًا تلقائيًا بعد فحص الملف.

**إعادة ضبط الترميز:** بعد نجاح نشر APK الرسمي `v1.0.0`، سيُحذف من قائمة Releases العامة ما تبقى من الإصدارات التجريبية السابقة 1.0.2 و1.0.4 و1.0.5، وتُزال الملفات الخاصة بها من الفرع الرئيسي. يُحتفظ بتاريخ التطوير في المستودع الخاص.

> مهم: لأن الإصدار الجديد يبدأ برقم بناء 1، لا يقبل Android تثبيته كتحديث فوق النسخ السابقة ذات رقم بناء أعلى. يُرجى أخذ نسخة احتياطية والتحقق من استعادتها قبل إلغاء التثبيت.
