# Official signed APK upload folder

ارفع هنا فقط ملف **APK رسمي موقّع** باسم الإصدار.

**الملف المطلوب حاليًا:** `Khaznaty-1.0.2-Release-SIGNED.apk`

عند رفعه إلى هذا المجلد والضغط على **Commit changes**، سيقوم GitHub Actions تلقائيًا بما يلي:
1. التحقق من توقيع التطبيق الرسمي.
2. التأكد من اسم الحزمة والإصدار والملف الصحيح.
3. إنشاء **GitHub Release v1.0.2** ونشر APK مع ملاحظات التحديث.
4. جعل الإصدار متاحًا للاستعلام داخل تطبيق خزنتي عبر GitHub API.
